# Housing Prices Regression Project
# Project Proposal: Ames Housing Regression

## Research Question
Which specific home features (e.g., square footage, neighborhood, year built) have the highest impact on final sale prices, and can we accurately predict prices using linear regression?

## Dataset
*   **Source:** Kaggle Ames Housing Dataset
*   **Link:** [Kaggle Dataset Link](https://kaggle.com)

## Literature Scan (Existing Work)
1.  *De Cock, D. (2011).* "Ames, Iowa: Alternative to the Boston Housing Data as an End of Semester Regression Project." Journal of Statistics Education. This paper outlines the original data collection and highlights the importance of removing outliers in the ground living area.
2.  *Standard Kaggle Kernels.* Various community implementations demonstrate that regularized regression models (Ridge/Lasso) perform exceptionally well due to the high number of categorical variables.
